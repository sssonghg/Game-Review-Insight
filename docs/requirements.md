# 요구사항

## 프로젝트 목표

오버워치 2와 이터널 리턴의 한국어 Steam 리뷰를 수집·분석한다.
사용자는 게임별 평가 흐름을 확인하고, 새 피드백의 추천·비추천
가능성과 비슷한 기존 리뷰를 볼 수 있다.

## 대상 사용자

- 두 게임의 이용자 평가를 살펴보려는 플레이어
- 리뷰 속 의견과 평가 변화를 파악하려는 게임 운영·기획 담당자

## 핵심 기능

### 1. 게임별 리뷰 대시보드

- 사용자는 오버워치 2와 이터널 리턴 중 하나를 선택할 수 있다.
- 선택한 게임의 날짜별 리뷰 수와 추천·비추천 비율을 볼 수 있다.
- 리뷰 목록을 조회할 수 있다.

### 2. 새 피드백 분석

- 사용자는 게임을 선택하고 피드백 글을 입력할 수 있다.
- 서비스는 직접 학습한 모델의 추천·비추천 예측 결과를 보여준다.
- 결과를 만든 모델 버전을 함께 기록한다.

### 3. 유사 리뷰 검색

- 서비스는 입력한 피드백과 의미가 비슷한 기존 리뷰를 보여준다.
- 다른 게임의 리뷰가 섞이지 않도록 선택한 게임에서만 검색한다.

## 이번 프로젝트에 포함

- 두 게임의 한국어 Steam 리뷰 수집·정제·저장
- 게임별 리뷰 조회와 평가 흐름 표시
- 추천·비추천 분류 모델의 직접 학습·평가
- 새 피드백 예측 및 유사 리뷰 검색
- 이후 단계에서 자동 수집, 비동기 처리, 캐시, 로컬 배포 구현

## 이번 프로젝트에서 제외

- 다른 게임과 스팀 외 플랫폼의 리뷰
- 결제 기능
- AWS 배포: 지금은 로컬에서 구현하고 추후 확장 가능하게 설정을 분리한다.

## 완료 기준

- [ ] 두 게임의 리뷰를 수집하고 다시 실행해도 중복 저장되지 않는다.
- [ ] 화면에서 게임별 리뷰와 날짜별 평가 흐름을 조회할 수 있다.
- [ ] 새 피드백을 입력하면 예측 결과와 모델 버전을 확인할 수 있다.
- [ ] 같은 게임의 유사 리뷰 3~5개를 확인할 수 있다.
- [ ] 모델 성능을 게임별 Precision·Recall·F1으로 평가해 기록한다.
