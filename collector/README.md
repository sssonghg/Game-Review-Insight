# Steam 리뷰 수집기

## 실행

프로젝트 최상위 폴더에서 실행한다.

python collector/collect_reviews.py

## 동작

- 오버워치 2와 이터널 리턴의 한국어 분류 리뷰를 요청한다.
- 게임별 최대 3페이지, 페이지당 최대 10개를 수집한다.
- cursor를 사용해 다음 페이지를 요청한다.
- 빈 리뷰 목록을 받으면 수집을 종료한다.
- 요청 오류가 발생하면 오류를 출력하고 실행을 중단한다.
- recommendationid를 기준으로 중복을 제거한다.
- 기존 파일과 합치며, 같은 ID는 새로 받은 내용으로 갱신한다.

## 저장 위치

- data/raw/2357570.json
- data/raw/1049590.json

원본 JSON 파일은 Git에 포함하지 않는다.

## 확인 결과

- 두 게임의 여러 페이지 수집 및 JSON 저장을 확인했다.
- 같은 데이터를 다시 수집해도 중복 저장되지 않는지 확인했다.
- 요청 오류 처리 코드는 추가했으며, 실제 오류 상황 검증은 아직 진행하지 않았다.
